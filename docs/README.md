# Design Docs

Design docs for geowittejr.com. Top-level decisions live in [`../project-plan.md`](../project-plan.md). Docs here go deeper on a single feature or change.

> This folder is **not** published to the site. Astro only builds `src/` and `public/`.

## Conventions

- **Start from the template:** copy [`_template.md`](_template.md).
- **Filename:** `NNNN-short-kebab-title.md`, numbered in order (e.g. `0001-dark-mode.md`).
- **Status:** `Draft` → `Accepted` → `Implemented`, or `Superseded by NNNN` / `Rejected`.
- **When accepted,** add a line to the Decision Log in `project-plan.md` that links back here.
- **Don't delete old docs.** Mark them superseded so the history stays readable.
